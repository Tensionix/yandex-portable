# Poppler Build Review

Poppler is a PDF rendering/extraction toolchain with GPL licensing. Windows binary packages can include additional native libraries with their own notices.

Before publishing a release archive that bundles Poppler binaries, identify the exact Poppler package, include the GPL/source information required by that package, and collect notices for any bundled native dependencies.

References:

- https://poppler.freedesktop.org/
- https://gitlab.freedesktop.org/poppler/poppler
