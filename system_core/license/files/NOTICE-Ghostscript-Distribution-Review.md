# Ghostscript Distribution Review

Ghostscript is available under the GNU AGPL or a commercial Artifex license. Redistributing Ghostscript in a bundled application requires deliberate license review.

Before publishing a release archive that bundles Ghostscript binaries, verify whether the AGPL release is acceptable for the whole distribution or whether a commercial license is required.

References:

- https://ghostscript.com/faq
- https://ghostscript.com/licensing/index.html
- https://ghostscript.com/releases/gsdnld.html
