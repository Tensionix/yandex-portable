ImageMagick is distributed under the ImageMagick License. Binary packages may also include or rely on delegate libraries for formats such as TIFF, JPEG, PNG, WebP, HEIF, XML, font rendering, and PDF/PostScript handling.

Before publishing a release archive that bundles ImageMagick binaries, include the ImageMagick license and review the exact package's included delegate libraries and notices.
