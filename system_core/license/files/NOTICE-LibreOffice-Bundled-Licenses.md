# LibreOffice Bundled License Review

LibreOffice is Free Software made available under MPL-2.0, with historical and bundled code under additional licenses. LibreOffice installations include their own license information and third-party notices.

Before publishing a release archive that bundles LibreOffice binaries, include the installed LibreOffice license files or the license information dialog/export from the exact build being redistributed.

References:

- https://www.libreoffice.org/licenses/
